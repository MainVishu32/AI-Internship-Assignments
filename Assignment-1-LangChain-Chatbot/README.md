# LangChain Gemini AI Chatbot

A simple multi-turn AI chatbot built using LangChain and Google's Gemini
language model.

The chatbot supports prompt templates, system instructions, conversation
memory, and interactive multi-turn conversations.

## Features

- Gemini LLM integration
- LangChain prompt templates
- System prompt
- Conversation memory
- Multi-turn conversations
- Interactive terminal-based chat
- Environment variable configuration
- Basic error handling

## Technologies Used

- Python
- LangChain
- Google Gemini
- python-dotenv
