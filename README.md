\# AI Internship Assignments



This repository contains the three assignments completed for the AI Engineer Internship technical evaluation.



\## Assignments



\### Assignment 1 — LangChain-Based Chatbot



A conversational AI chatbot built using LangChain and Google Gemini.



\*\*Technologies:\*\*

\- Python

\- LangChain

\- Google Gemini

\- Conversation Memory



\### Assignment 2 — AI Agent with Tool Calling



An AI agent capable of selecting and using tools based on the user's request.



\*\*Tools:\*\*

\- Calculator

\- Time/Timezone



\*\*Technologies:\*\*

\- Python

\- LangChain

\- Google Gemini



\### Assignment 3 — End-to-End AI Application



An AI Study Assistant with a web interface and REST API backend.



\*\*Technologies:\*\*

\- Python

\- FastAPI

\- LangChain

\- Google Gemini

\- HTML

\- CSS

\- JavaScript
